# PPT 图纸说明轻量标记规则

适用范围：制图工作台的 PPT 图纸说明文本。agent 生成说明文字时应先按本规则整理，用户也可以在 PPT 预览里直接编辑，系统会映射回同一份文本。

## 规则

- `**小标题：**` 表示说明小标题或条目标题，导出为加粗、略大字号、全局品牌色。
- `*品牌强调*` 表示正文中的重点词，导出为加粗、全局品牌色。
- 未标记文字为正文，导出为深灰常规字重。
- 空行用于分段。

## 示例

```text
**停车配套：** 沿太阳岛二路与珠峰路沿街线性布置机动车临时停车位与非机动车位。
**景观休闲配套：** 在内部景观绿地中设置多处遮阳休憩处，满足*酒店运营*与城市服务需求。
```

全局品牌色由 PPT 出图面板的“全局品牌色”控制，默认 `#D9882B`。不要把品牌色写成每段独立颜色；后续统一换色时只改全局配置。
