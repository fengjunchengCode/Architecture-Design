# Output Style

建筑设计输出要服务后续方案推进，保持可追溯、可校验、可接着画图。

## 基本格式

- 优先用短段落、表格、清单。
- 每条关键判断标明来源：任务书、区位图、现场照片、DWG、聊天记录、agent 推断。
- 对推断写置信度或“待复核”。
- 不写空泛形容词，如“品质感强”“空间丰富”，除非说明具体空间策略。

## 推荐小节

阶段正文通常包含：

1. 本阶段输入
2. 已确认事实
3. Agent 判断
4. 低置信字段
5. 阻塞项 / 待问甲方
6. 对下游阶段的影响

## 设计判断边界

- S0 建档，不做完整设计策略。
- S1 分析区位和场地语义，不计算 DWG 面积。
- S2 处理几何和地形，不替代方案判断。
- S3 做面积和强排依据，不输出最终设计。
- S4 汇总问题，不新增无来源事实。
- S9 组织汇报，不反向改核心数据。
